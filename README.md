Automação de organização de documentos com Python (AODP)

Objetivo: 
Fazer a organização dos documentos com direecionamento para suas determinadas pastas de acordo como o script.

Funcionalidades:
- Separa os arquivos por tipo (imagens, documentos, vídeos etc.)
- Cria as pastas automaticamente se não existirem
